# Página timelines (private)

Lista as timelines do usuário por categoria (filmes, séries, animes, franquias).

A página só compõe: componentes de `components/` e a lógica de `actions/`.

## Componentes
`atoms/StatusMessage`, `molecules/TimelineCard`, `organisms/TimelineDetail`

## Actions
`actions/timelines/mytimelines`, `actions/helpers/timelines`
