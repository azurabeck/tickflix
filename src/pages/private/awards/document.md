# Página awards (private)

Página de uma premiação: grade de edições -> detalhe da edição (indicados + progresso).

A página só compõe: componentes de `components/` e a lógica de `actions/`.

## Componentes
`organisms/AddDataModal`, `organisms/EditionDetail`, `organisms/EditionGrid`, `organisms/MovieDetail`, `atoms/Modal`, `atoms/PageShell`

## Actions
`actions/awards/dashboard`, `actions/awards/editions`
