# Página anime (private)

Página Animes: cada section pede o que precisa; o dashboard confere cache, atualização e o pedido ao backend.

A página só compõe: componentes de `components/` e a lógica de `actions/`.

## Componentes
`organisms/EpisodicCatalog`

## Actions
`actions/animes/dashboard`, `actions/animes/hero`, `actions/animes/myanimes`, `actions/animes/mostwatchedrank`, `actions/animes/mynotesrank`, `actions/animes/bestratedon`
