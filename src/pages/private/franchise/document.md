# Página franchise (private)

Página de uma franquia (Marvel, Star Wars...): todos os filmes e séries, marque o que já viu.

A página só compõe: componentes de `components/` e a lógica de `actions/`.

## Componentes
`atoms/MediaGrid`, `atoms/PageShell`, `atoms/StatusMessage`, `molecules/MediaCard`

## Actions
`actions/franchises/catalog`, `actions/franchises/dashboard`, `actions/helpers/opencard`
