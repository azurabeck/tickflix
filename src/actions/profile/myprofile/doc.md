# actions/profile/myprofile

**Página/ciclo:** `profile` → `myprofile`

Ciclo "editar perfil": nome, avatar e gêneros preferidos; só habilita salvar quando algo mudou. usado em: ProfileForm

## Funções (na ordem em que o ciclo acontece)
- `PREFERRED_GENRES` — Gêneros que o usuário pode marcar como preferidos. usado em: ProfileForm
- `useMyProfile` — Ciclo "editar perfil": nome, avatar e gêneros preferidos; só habilita salvar quando algo mudou. usado em: ProfileForm
