# actions/presentation/codesnippet

**Página/ciclo:** `presentation` → `codesnippet`

Tira do código-fonte o trecho pedido. Devolve null se não achar (o código mudou): quem mostra avisa, em vez de inventar. usado em: presentation/cycles

## Funções (na ordem em que o ciclo acontece)
- `extractSnippet` — Tira do código-fonte o trecho pedido. Devolve null se não achar (o código mudou): quem mostra avisa, em vez de inventar. usado em: presentation/cycles
- `tokenizeLine` — Divide uma linha de código em pedaços coloridos: comentário, texto entre aspas, palavra-chave e o resto. Simples de propósito (não é um parser). usado em: CodeBlock
