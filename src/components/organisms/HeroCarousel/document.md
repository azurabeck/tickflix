# HeroCarousel (organismo)

Carrossel de trailers do topo: passa sozinho pro próximo quando o vídeo acaba.

## Props
- `items`: `HeroTrailer[]`
- `loading?`: `boolean`

## Depende de
`components/atoms/PageContainer`, `components/atoms/Spinner`, `actions/helpers/herotrailer`

## Estilo
`style.scss` — classes `hero-carousel` e `hero-carousel__*` (BEM).
