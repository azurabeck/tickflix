# SuggestionRefreshCard (átomo)

Card que aparece no fim das sugestões da IA para gerar novas (com estados de carregando/erro).

## Props
- `loading?`: `boolean`
- `onRefresh`: `() => void`

## Depende de
Nada além de bibliotecas.

## Estilo
`style.scss` — classes `suggestion-refresh-card` e `suggestion-refresh-card__*` (BEM).
