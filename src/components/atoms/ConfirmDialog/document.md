# ConfirmDialog (átomo)

Caixa de confirmação (título, mensagem, confirmar/cancelar, `danger` pinta de vermelho). Quem controla a abertura é o `ConfirmProvider` (`contexts/Confirm`).

## Props
- `onResult`: `(confirmed: boolean) => void`

## Depende de
Nada além de bibliotecas.

## Estilo
`style.scss` — classes `confirm-dialog` e `confirm-dialog__*` (BEM).
