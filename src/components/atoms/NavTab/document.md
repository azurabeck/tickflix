# NavTab (átomo)

Aba da barra de navegação: link (com `to`) ou botão que abre um menu (com `onClick`).

## Props
- `children`: `ReactNode`
- `to?`: `string`
- `active?`: `boolean`
- `onClick?`: `() => void`
- `expanded?`: `boolean`

## Depende de
Nada além de bibliotecas.

## Estilo
`style.scss` — classes `nav-tab` e `nav-tab__*` (BEM).
