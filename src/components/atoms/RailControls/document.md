# RailControls (átomo)

Setas de rolar a fileira + link opcional "ver todos" (usa o estado de `useScrollRail`).

## Props
- `rail`: `RailState`
- `seeAllLabel?`: `string`
- `onSeeAll?`: `() => void`

## Depende de
`actions/helpers/scrollrail`

## Estilo
`style.scss` — classes `rail-controls` e `rail-controls__*` (BEM).
